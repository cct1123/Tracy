# Physics definitions and validity

This document maps the workbench's numerical quantities to their implemented definitions. The application models coaxial geometric rays in scalar isotropic media. It has no diffraction, bulk absorption, coating, coherent interference, birefringent propagation, or polarization-state transport. Reference/display rays never belong to a physical sample population.

## Coordinates, surfaces and materials

| Quantity / control                    | Definition and units                                                                                                                                                               | Implementation / validation                                                                   |
| ------------------------------------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | --------------------------------------------------------------------------------------------- |
| Component z, detector z, source x/y/z | Global Cartesian coordinates in mm; positive z is the initial propagation axis. Geometry remains coaxial.                                                                          | `model/components.js`, `core/sources.js`; independent finite-point and reversed-lens fixtures |
| Radius R / curvature c                | Radius in mm; c = 1/R in mm⁻¹. c = 0 denotes a plane. Positive R places the sphere centre toward +z.                                                                               | `core/surfaces.js`; analytical lensmaker and RayOptics singlets                               |
| Thickness                             | Difference between successive surface vertex z coordinates, mm. It is not the off-axis ray's geometric segment length.                                                             | `model/components.js`; plate OPL and exact-ray comparisons                                    |
| Clear diameter / semi-aperture        | Circular clear diameter in mm; stored `sd` is its radius. Import keeps per-surface radii unless the explicit override is active. Radius is checked at the actual sag intersection. | `core/surfaces.js`, import schema; aperture regressions and independent clipping              |
| Conic constant K                      | Dimensionless; base sag `c r² / (1 + √(1 − (1+K)c²r²))`. K = 0 is spherical; K = −1 is parabolic.                                                                                  | `sagSD`, `surfNormal`; analytical paraboloid, RayOptics                                       |
| Even-asphere coefficient a[k]         | Adds `a[k] r^(2k)` to sag. Units mm^(1−2k). `parm[1]` is r², `parm[2]` r⁴, etc.                                                                                                    | `asphSD`; exact polynomial derivative and external even-asphere case                          |
| Surface normal / ray direction        | Unit Cartesian vectors; dimensionless direction cosines. Snell's law uses the normal against the incident direction.                                                               | `core/surfaces.js`; Snell/TIR and full-RayOptics direction comparisons                        |
| Wavelength                            | Vacuum wavelength: µm in numerical APIs, nm in UI. F/d/C = 486.1327 / 587.5618 / 656.2725 nm.                                                                                      | `core/wavelengths.js`, `simulation-state.js`; spectral and independent catalog tests          |
| Scalar refractive index n(λ)          | Positive, real phase index. Sellmeier `n² = 1 + Σ Bᵢ λ²/(λ²−Cᵢ)` with λ in µm; Cᵢ in µm². Ambient air is exactly 1.                                                                | `core/materials.js`; independent N-BK7/N-F2 F/d/C values                                      |
| Field / aim angles                    | Degrees in controls; source direction is normalized `[tan(fieldX), tan(fieldY), 1]`. These are x-z and y-z projected angles, not spherical azimuth/elevation.                      | `sourceBasis`, `core/sources.js`; source/simulation tests                                     |
| Point-source NA                       | Dimensionless `sin(α)` in incident n = 1 air; α is cone half-angle. Uniform-pupil mode instead defines its directions by the explicit target plane/disk.                           | `generateSourceSamples`; source-distribution tests                                            |

Domain-invalid conic intersections and total internal reflection do not produce refracted directions. A circular aperture includes a 1e-7 mm numerical edge allowance; this is not a machining tolerance. Surface sag or slope singularities have separate guards and are outside the ordinary fixture domain.

Strict material mode blocks unresolved names, known out-of-range wavelengths, dispersion poles, and invalid numerical coefficients. Exploratory mode can use n = 1.52 for unresolved glass or extrapolate a known fit, with persistent approximate-material warnings. Provenance and wavelength validity are separate: a known coefficient array with an unverified source or undocumented interval remains visibly unverified. Current metadata identify MgF₂ and sapphire as scalar isotropic approximations. Fused silica's published absolute-index convention and Schott's air-relative indices are documented in their provenance; the solver approximates ambient air as 1 for both.

## Sampling coordinates and three separate weights

For active wavelength j, the source's nonnegative spectral input is sⱼ. The normalized spectral weight is **qⱼ = sⱼ / Σ sⱼ**. Default active F/d/C entries each have q = 1/3. This is a three-line source model with equal radiant-power weights, not a white-light spectrum or a photopic/luminous weighting. Display color has no numerical role.

For physical sample i, **aᵢⱼ** is its normalized source/quadrature weight, with Σᵢ aᵢⱼ = 1 before tracing. A reference ray always has a = 0. Geometric coordinates and sample weights are stored separately. The optical branch carries **Pᵢⱼ**, a scalar fraction of that ray's incident power after its Fresnel interactions. A successful primary detector sample has delivered statistical weight **wᵢⱼ = aᵢⱼ qⱼ Pᵢⱼ**. Clipped/failed rays deliver zero. Sequential geometry assigns P = 1 and therefore estimates geometric survival only.

The source model defines what the quadrature samples mean:

| Pattern / distribution                  | Coordinate construction and implied population                                                                                                    | Limits                                                                                                                                                                                                           |
| --------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| 3-D pupil disk                          | Golden-angle azimuth and `ρ² = (i+1/2)/N`. Equal weights approximate uniform area in the unit disk.                                               | Deterministic finite quadrature; increase N to assess sampling convergence.                                                                                                                                      |
| Meridional fan                          | Equally spaced coordinates along the y diameter, endpoints included.                                                                              | A discrete 1-D diagnostic population, not a uniformly illuminated 2-D aperture.                                                                                                                                  |
| Sagittal fan                            | Equally spaced coordinates along the x diameter.                                                                                                  | Same 1-D limit.                                                                                                                                                                                                  |
| Ring                                    | Uniform azimuth at the outer normalized radius.                                                                                                   | A discrete ring diagnostic, not pupil area.                                                                                                                                                                      |
| Collimated, entrance-pupil illumination | Samples are aimed to the modeled stop/pupil targets; source directions are parallel.                                                              | Equal target weights describe this discrete bundle. Nonlinear real-ray stop aiming does not include an irradiance Jacobian. Reducing a stop can redefine this bundle, so total source collection is unavailable. |
| Collimated, fixed source disk           | Disk diameter and z plane are independent of the entrance pupil; parallel rays pass through its sampled coordinates.                              | In 3-D disk mode this defines finite illuminated source power. A smaller stop rejects samples instead of shrinking the source.                                                                                   |
| Point, uniform solid angle              | With `u = ρ²`, `cos θ = 1 − u(1−cos α)`; azimuth from the disk. Equal weights approximate constant emitted power per solid angle within the cone. | This is the finite modeled cone, not all 4π steradians.                                                                                                                                                          |
| Point, uniform angular                  | `θ = α ρ²`; azimuth from the disk. Equal weights approximate constant power per dθ dφ.                                                            | Not an isotropic emitter; the different Jacobian is intentional and documented. The legacy helper's angular-disk mapping is retained only for compatibility tests.                                               |
| Point, uniform pupil                    | Rays travel from the common source point to equal-area coordinates on an explicit disk at `pupilZMm`.                                             | Describes prescribed pupil illumination; the source is not isotropic. Diameter/plane, rather than NA/aim, determine the distribution.                                                                            |
| Gaussian weighting                      | Multiply the base discrete population by `exp(−2ρ²/σ²)`, then renormalize; σ is the dimensionless normalized coordinate scale.                    | Truncated to the defined population. For angular sources this weights quadrature coordinates; it is not automatically a physical Gaussian beam.                                                                  |
| Custom weighting                        | User supplies nonnegative weights matching sample count, with positive sum; they are normalized.                                                  | Defines the discrete source population explicitly. It does not create an unprovided continuous source model.                                                                                                     |

The primary numerical API is `generateSourceSamples` in `core/sources.js`. `sampling.count` controls analysis quadrature per positive-weight active wavelength. `display.count` selects visible paths from that population. Changing visibility, line brightness, chief visibility, or ghost display never changes physical statistics. The central reference is calculated regardless of whether it is drawn.

## Detector and power metrics

The sum below runs over physical samples and active wavelengths. Iᵢⱼ is 1 for an accepted primary detector intersection and 0 otherwise. A primary topology inconsistency blocks the complete quantitative result instead of being presented as ordinary vignetting.

| Display / result quantity                 | Mathematical definition / normalization                                                                      | Units and validity                                                                                                                                                                                 |
| ----------------------------------------- | ------------------------------------------------------------------------------------------------------------ | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Analysis / traced rays                    | N times the number of active wavelengths having positive source weight.                                      | Count, excluding references and ghost branches.                                                                                                                                                    |
| Detector hits                             | Number of successful physical primary samples.                                                               | Count; does not encode delivered power or source weights.                                                                                                                                          |
| Vignetted samples                         | Traced count minus detector-hit count.                                                                       | Count. Includes geometric misses/TIR without a detector continuation, not just stop clipping.                                                                                                      |
| Bundle survival / transmission            | **S = Σ qⱼ aᵢⱼ Iᵢⱼ**.                                                                                        | Fraction or percent of the defined input population; source-weighted, independent of Fresnel losses.                                                                                               |
| Vignetted fraction                        | **1 − S**.                                                                                                   | Weighted fraction, which need not equal clipped count / traced count under custom weights.                                                                                                         |
| Primary sampled-bundle power / throughput | **T = Σ qⱼ aᵢⱼ Iᵢⱼ Pᵢⱼ**.                                                                                    | Fraction or percent of the defined input population's modeled power. Sequential mode reports S. Excludes ghost hits.                                                                               |
| Conditional Fresnel transmission          | **T/S**, when S > 0.                                                                                         | Mean Fresnel power among geometrically surviving weighted samples. Undefined without survivors. Sequential mode is 1 when defined.                                                                 |
| Defined source collection                 | T, available only with area-disk sampling and a point source or independent fixed-disk illumination.         | Fraction of the specified finite source cone or disk. No absolute watts or outside-cone/4π extrapolation. Unavailable for pupil-retargeted collimated bundles and diagnostic fan/ring populations. |
| Spot centroid x̄, ȳ                        | `Σ w x / Σ w`, `Σ w y / Σ w` at the detector plane.                                                          | mm, primary physical hits only. Wavelengths combine with source weights and delivered power.                                                                                                       |
| RMS spot radius                           | **√[Σ w ((x−x̄)²+(y−ȳ)²) / Σ w]**.                                                                            | mm internally, µm when small in UI. A centroid-referenced geometric radius; not diameter, diffraction spot size, or distance from axis.                                                            |
| Maximum spot radius / scale extent        | Largest Euclidean radius about that weighted centroid among positive-weight physical hits.                   | mm. Not an encircled-energy radius; a low-weight outlier can control auto scale.                                                                                                                   |
| Per-wavelength spot / power               | Same definitions restricted to one wavelength, with its sample weights normalized at launch.                 | RMS mm; survival/power fractions. A wavelength with zero input spectral weight is not traced.                                                                                                      |
| A/B changes                               | Report B's and A's geometry, detector z, per-wavelength values and metrics; an explicit difference is B − A. | Same units as its source quantity. Compare source spectrum, distribution, count, engine, apertures and materials as well as geometry.                                                              |

All statistics return unavailable/null when no positive delivered weight exists. They do not replace a zero-power cloud with equal-power rays. A physically sampled on-axis ray is allowed to carry weight; an added chief/reference ray at the same coordinates is a separate zero-weight object.

Implementation: `core/simulate.js` aggregates transmission/survival and per-wavelength results; `analysis/metrics.js` computes centroids and spot radii. Validation: simulation chief/visibility invariance, source-area collection, weighting regressions, analytic Fresnel products, and independent ray/power fixtures.

## Accumulated and relative OPL

For a ray with physical segment lengths Lₖ, **OPL = Σ nₖ(λ)Lₖ**, in mm. It begins at the engine's stated ray launch point and ends at the detector. Numerical intersection offsets do not remove physical path length. OPL is a phase-index optical length; it is not a group delay or travel-time model.

At each wavelength choose the successfully traced zero-weight central reference. If it is blocked, use the physical surviving sample with the smallest normalized radius ρ and report that fallback. For a physical detector sample:

**Relative OPLᵢⱼ = 1000 × (OPLᵢⱼ − OPLreference,ⱼ)**, in µm.

| Relative OPL panel quantity     | Definition                                                                                                                                                                          |
| ------------------------------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Pupil coordinates u/v, radius ρ | Normalized launch/target sampling coordinates; `ρ = √(u²+v²)`. Angular sources reuse these quadrature coordinates; this is not a reconstructed exit pupil.                          |
| Relative OPL color              | Signed path difference in µm to the wavelength's reference. Color range is an explicitly displayed plotting scale.                                                                  |
| Relative OPL RMS                | `√(Σ w ΔOPL² / Σ w)`, physical samples across wavelengths. The reference contributes no weight. This RMS is about the specified zero reference, not a de-meaned standard deviation. |
| Relative OPL PV                 | Largest within-wavelength `max(ΔOPL) − min(ΔOPL)` over physical samples. Spectral references are separate; a cross-spectrum global span is not reported.                            |
| Transverse reference separation | `1000 × hypot(x−xref, y−yref)`, µm. A geometric separation from the central reference, not a classical aberration coefficient.                                                      |

This diagnostic neither subtracts an ideal reference sphere nor assigns the incident phase of an oblique plane wave to different launch coordinates. It is therefore not wavefront error, wavefront aberration, Strehl ratio, PSF, or MTF. Changing the launch plane or source model can change it. Changing chief display visibility cannot change it because the reference is always computed.

Implementation: accumulated length in `core/sequential.js` / `core/fresnel.js`; differences and weighted summaries in `analysis/metrics.js::analyzeRelativeOPL`. `analyzeAberration` remains only a compatibility alias. Validation: independent OPL values, analytic plate/ghost path lengths, and reference-display invariance tests.

## Entrance pupil, plots and focus

The entrance pupil is the **paraxial image of the stop through preceding surfaces**. With a reduced-angle matrix `[A B; C D]` from first surface to stop, its z is `firstSurfaceZ + B/A`; diameter is `stopDiameter/|A|`, subject to a prescription's explicit ENPD/STOP footprint rules. A near-zero A produces a pupil at infinity. A user-created aperture takes precedence over an imported STOP. Without a stop, the prescription or first-surface fallback defines sampling diameter; this is locally labeled. These estimates are not an exact finite-field pupil boundary, and real-ray aiming can fail for individual targets.

The legacy bench EPD is an aperture/sampling metadata value in mm. The actual displayed entrance-pupil diameter and the physical source disk diameter can differ. Component and surface totals are counts, not optical metrics. Catalog focal lengths/radii are source specifications, not values recalculated from arbitrary edited geometry; their provenance/approximation labels must be retained.

Plot coordinates and labeled bounds are in mm for spot x/y and detector z, and µm for Relative OPL. Auto scale adapts bounds to the current result; locked scale keeps the user-selected bounds; shared scale includes compared results. A previous-result overlay retains its original physical values. Plot line thickness, opacity and wavelength RGB colors are display choices and never optical power measurements.

Focus Scan samples a uniform detector-z grid over the chosen interval and computes the same source-, spectrum-, and power-weighted centroid RMS at each point. The reported best z is the **best tested grid point**, not a continuous optimum. Its resolution is `(to − from)/(steps − 1)` mm. The source, wavelengths, weights, ray count and geometry stay fixed; only the detector position changes. If clipping changes with z, RMS is conditional on surviving hits and may become smaller by discarding rays, so survival/power must be considered alongside the curve. Moving the detector to the minimum is an explicit action.

Paraxial EFL/focal z in the independent suite are reference validation quantities, distinct from finite-ray Focus Scan. Their conventions are described in [external validation](external-validation.md).
