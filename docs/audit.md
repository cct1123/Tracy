## Inspection coverage

- Numerical engine: vector, conic/even-asphere intersections, normal/refraction/Fresnel, sequential path, region topology, pupil imaging and real-ray aiming, source generation, material registration and wavelength conversion.
- Imports/data: ZMX/ZAR decoding, units/STOP/ENPD/PUPD, shared surface/schema validation, library/component reversal, imported aperture preservation, catalog integrity/provenance and custom-glass save/load.
- Application: bench/model ownership, action/history/selection, renderer/Three disposal and ray color, plot calculations, source controls, shell/status/camera, local project recovery, production packaging/static routes.
- Validation/documentation: all pre-existing tests, runtime diagnostics, example projects, user/technical/architecture guides and previous improvement plan. Frozen prototype is retained and never shipped/executed as the application.

The [physics definitions](physics-definitions.md) map quantities to mathematical definitions, units, normalization, validity and tests. [Independent comparisons](external-validation.md) bound the demonstrated numerical domain. [Benchmarks](../outputs/current-benchmark.json) measure raw calculation cost; Worker use improves responsiveness, not physical accuracy or raw speed.

## Remaining risks

Finite lens sidewalls are unspecified. Tracy detects inconsistent regions and cannot calculate trustworthy edge/sidewall scattering. Ghost paths have explicit power/bounce budgets and incomplete edge paths are warnings; no total ghost-inclusive collection claim is made. Legacy catalog materials without authoritative provenance/ranges remain visibly unverified. Tangencies, singular conic rims and arbitrary noncoaxial systems are outside the reference matrix. Browser storage can be evicted: JSON export remains the portable backup. Shared plot scales preserve units; differing illumination/clipping populations must still be interpreted with the visible settings and survival fraction.
