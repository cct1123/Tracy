# Tutorial screenshot provenance

The catalog (`02`) and analysis (`07`) pairs were recaptured on 2026-09-30 from the H007 candidate based on `512d480`, using isolated Playwright Chromium at `http://127.0.0.1:5198/`. These are authentic rendered screenshots; no controls, results, colors or labels were generated or retouched. [Capture evidence and application source hashes](../../../outputs/wavefront-tutorial-capture.json) identify the exact candidate. Both themes were selected through the application UI.

The other 18 PNGs remain historical browser screenshots captured on 2026-09-21 at `http://127.0.0.1:5195/`, from application commit `f5d3abd0f826899b415f9e073abd5c5c349b6d38`. Their source and capture conditions below are preserved; they predate the newer precision and wavefront controls.
The historical browser used its normal 838 × 912 CSS-pixel viewport; H007 captures use a 1440 × 1100 viewport with targeted element screenshots. Focused images are rectangular crops of the original viewport capture. No controls, results, colors or labels were generated or retouched. Docks were opened/closed and panels scrolled through the ordinary interface. Each numbered function has matching `-day.png` and `-night.png` files; themes were changed through View.

The reference bench is the included 85301 doublet, collimated pupil-targeted illumination, d-line 587.56 nm, 49 analysis samples, Fresnel engine, strict materials and ghost reflections unchecked. The local tutorial browser origin is separate from hosted projects. The hosted Site remains at the earlier application revision `7bfee883020797977a9b17769811977f58a170bb`; these images document the captured `f5d3abd` revision.
